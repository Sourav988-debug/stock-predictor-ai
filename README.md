# Stock Price Prediction AI

Stock Price Prediction Web App using Linear Regression and LSTM with a Flask backend and interactive Chart.js dashboard to visualize historical and future stock trends.

## Features

- Historical stock data collection using Yahoo Finance
- Data preprocessing and scaling
- Linear Regression model for trend prediction
- LSTM deep learning model for time-series forecasting
- Model comparison using RMSE
- Flask REST API for predictions
- Interactive frontend dashboard using Chart.js
- Visualization of historical vs predicted stock prices

## Technologies Used

- Python
- Flask
- TensorFlow / Keras
- Scikit-learn
- Pandas & NumPy
- Chart.js
- HTML / CSS

## Project Workflow

1. Data collection
2. Data preprocessing
3. Train Linear Regression
4. Train LSTM model
5. Compare model performance
6. Serve predictions through Flask API
7. Visualize predictions using an interactive dashboard
